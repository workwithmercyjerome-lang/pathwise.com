# PathWise

**Find your path. Build your future.**

PathWise is a career guidance and education platform designed to help students and young people in **Nigeria, Ghana, and across Africa** make more informed decisions about their education and career paths.

The platform brings career exploration, self-assessment, education guidance, skills development, mentors, and opportunities into one place.

## ✨ Features

* **Career Assessment** — A guided quiz that helps users identify career paths that match their interests and strengths.
* **Career Explorer** — Browse careers with information about roles, skills, education requirements, salaries, and career outlook.
* **Search & Filters** — Find relevant careers and opportunities more easily.
* **Career Comparison** — Compare different career paths side by side.
* **Skills Guidance** — Discover useful technical and professional skills for different career paths.
* **Mentors** — Explore mentors and professionals across different career fields.
* **Country Guide** — Education and admission information tailored to Nigeria and Ghana, including relevant examination and education bodies.
* **Opportunities** — Discover jobs, internships, scholarships, and other career-building opportunities.
* **User Accounts** — Create an account, sign in, save careers, and keep track of assessments.
* **Responsive Design** — Built to work across desktop and mobile devices.

## 🚀 Running Locally

Clone the repository and install the dependencies:

```bash
npm install
```

Set up your environment variables in `.env`, configure the database, and run the Prisma migrations.

Start the backend with:

```bash
node server.js
```

The API runs locally at:

```text
http://localhost:4000
```

Open `Pathwise.html` with VS Code Live Server to use the frontend.

## 🎯 Project Goal

PathWise was created to make career and education guidance more accessible, especially for young people who may not have access to professional career counselling or strong support systems.

The long-term vision is to grow PathWise into a practical platform where users can **discover careers, understand the education required, develop relevant skills, connect with mentors, and find opportunities to build their future.**
